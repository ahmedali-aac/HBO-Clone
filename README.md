# 🎬 HBO Max Clone - Premium Streaming UI

A high-fidelity clone of the **HBO Max** landing page, built to showcase advanced frontend development skills, pixel-perfect UI design, and responsive layouts.

🔗 **Live Demo:** [Watch it Live](https://ahmedali-aac.github.io/HBO-Clone/)

---

## 📽️ Project Overview

This project is a visual recreation of one of the world's leading streaming platforms. The focus was on mastering the "Dark Mode" aesthetic, handling high-quality media assets, and ensuring a seamless browsing experience across all devices.

### Key Features:
- **Cinematic Hero Section:** Dynamic featured content with high-impact visuals.
- **Horizontal Scroll Carousels:** Smooth browsing for movies and TV shows.
- **Pixel-Perfect UI:** Exact replicas of HBO’s typography, color palette, and spacing.
- **Fully Responsive:** From 4K monitors to small mobile screens, the layout adapts perfectly.
- **Hover Interactions:** Smooth scaling effects on movie posters for a premium feel.

---

## 🛠️ Built With

- **HTML5:** Structured for high-density content.
- **CSS3 (Advanced):** Used Flexbox, CSS Grid, and custom transitions for the "Streaming" look.
- **JavaScript:** For interactive carousels and navigation behavior.
- **Google Fonts:** Integration of clean, modern sans-serif typography.
